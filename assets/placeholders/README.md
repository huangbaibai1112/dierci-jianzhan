# 素材替换指引 (Assets Replacement Guide)

当前页面已集成矢量 SVG 占位图，确保无素材时页面视觉依旧完整、优雅、不破损。

当您准备好真实图片素材后，可直接将图片放置在本目录或将代码中的路径替换为您的素材地址：

* **当前文件**：`assets/placeholders/hero-eleanor.svg`
* **建议比例**：`4:3.4` 或 `800 × 680px`
* **风格建议**：50+ 单身女性/男性生活特写，自然日光、面带温暖微笑、无厚重滤镜。
